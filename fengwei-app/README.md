# 風味記帳系統 v1

店長下班用平板輸入，Google 試算表自動算出每月盈餘和股東分紅。

- **免費**：只用 Google 試算表加 Apps Script
- **不會算錯範圍**：所有資料都存在流水帳裡，新員工、新項目都會自動算進去
- **自動提醒**：外送沒對帳、現金差太多、漏填哪幾天、員工沒填薪資、股東比例不是 100%

---

## 一、安裝步驟（大約 10 分鐘，只要做一次）

1. 開一份**新的** Google 試算表，命名為「風味記帳」。
2. 上方選單點 **擴充功能 → Apps Script**。
3. 左邊的 `程式碼.gs`：把裡面的內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容。
4. 左邊按 **＋ → HTML**，檔名打 `Index`（不要加 .html），貼上 `Index.html` 的全部內容。
5. 左邊齒輪 **專案設定** → 勾選「在編輯器中顯示 appsscript.json」→ 回到編輯器打開 `appsscript.json`，貼上本資料夾的同名檔案內容（主要是把時區設成台北）。
6. 按上方 **儲存** 💾。
7. 回到試算表，**重新整理頁面**。上方會出現「**風味記帳**」選單，點 **① 初始化（第一次使用）**。
   - 第一次會要求授權：選你的帳號 → 進階 → 前往（不安全）→ 允許。這是你自己寫的程式，所以 Google 會這樣提示。
8. 回到 Apps Script，右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網頁有 PIN 碼保護，店長不需要登入 Google）
   - 按「部署」，複製**網頁應用程式網址**。
9. 在平板用 Chrome／Safari 打開這個網址 → 分享 → **加入主畫面**，之後就像 App 一樣點開使用。

> 以後如果更新程式碼：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。

## 二、初始化後要先改的設定

| 分頁 | 要做的事 |
|---|---|
| `設定_店家` | **改掉預設 PIN**（店長 1234、管理 9999）。手續費率預設 2%。現金差額預設**不計入盈餘**，警示門檻 500 元 |
| `設定_股東` | 已填好：大埔店 豐吉 60／浩勤 20／呀肥 20；中正店 浩勤 65／豐吉 35 |
| `設定_進貨分類` | 已填 19 類，**牛亨從 2026-10 起停用**（以前的紀錄還在）。要停用某一類，就在「停用月份」填 `yyyy-MM` |
| `設定_員工` | 刪掉兩筆範例，填入真實員工。這裡填的是「**預設值**」，每個月在網頁上可以再改 |

| 功能 | 店長 PIN | 管理 PIN |

## 四、計算規則

```
實際營收 = 現場營收 + Panda 實際入帳 + Uber 實際入帳
盈餘     = 實際營收 − 進貨 − 人事成本 − 固定支出 − 其他支出 − 線上手續費(全支付+LINE)×費率
可分配   = 盈餘 − 員工分紅 − 年終預留 − 其他扣除
股東分紅 = 可分配 × 各股東比例
```

- **人事成本** = 「薪資」類＋「公司負擔」類。「預支」只影響實發，不算成本。
- **現金差額**另外列出，不算進盈餘。要算進去，到 `設定_店家` 改成「是」。
- **現場支出**（收銀機直接付的錢）只用來對現金。進貨請另外在「進貨」登記，才不會重複扣。
- **當月還沒結束**的報表會標示「進行中」，數字只供參考。

## 五、報表分頁（自動產生，不要手動改）

- `報表_月結`：每店每月一行，包含營收、成本、盈餘、可分配、進貨和人事佔比
- `報表_分紅`：每個股東每月的分紅金額（可以用樞紐分析表做季合計）
- `報表_進貨分類`：各分類每月金額和佔營收比例
- `警示`：所有需要注意的事項

報表會在每次儲存後更新，每天凌晨 2 點也會自動重算一次。也可以手動點 **風味記帳 → ② 重新計算報表**。

## 六、改錯資料

- **每日結帳**：選同一天重新填，儲存就會覆蓋。
- **進貨、支出、扣除**：在清單上按「刪除」，再重新新增。
- **人事**：點員工重新編輯，儲存就會覆蓋。
- 管理者也可以直接在試算表的資料分頁刪除整列。
