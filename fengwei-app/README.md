# 風味記帳系統 v2（離線版）

平板、手機、電腦都能用。**沒網路也能打開、能記帳**，連上網路後會自動同步到 Google 試算表。

```
 ┌─────────────┐   有網路時自動同步   ┌─────────────────────┐
 │ App（每台裝置）│ ───────────────▶ │ Google 試算表（總帳本）  │
 │ 資料先存在本機  │ ◀─────────────── │ 存放所有記帳資料         │
 └─────────────┘   拿回其他裝置的資料   └─────────────────────┘
   放在 GitHub Pages（免費）            Apps Script 同步服務（免費）
```

| 資料夾 | 是什麼 |
|---|---|
| `docs/` | App 本體（GitHub Pages 會發布這個資料夾） |
| `fengwei-app/Code.gs` | Google 試算表的同步服務 |
| `docs/compute.js` | 計算邏輯。App 和試算表**共用同一份**，要貼到 Apps Script |

---

## 一、架 Google 試算表同步服務（大約 10 分鐘，只做一次）

1. 開一份**新的** Google 試算表，命名為「風味記帳」。
2. 選單 **擴充功能 → Apps Script**。
3. 左邊的 `程式碼.gs`：刪掉原本內容，貼上 `fengwei-app/Code.gs` 的全部內容。
4. 左邊按 **＋ → 指令碼**，命名為 `compute`，貼上 `docs/compute.js` 的全部內容。
5. 左邊齒輪 **專案設定** → 勾選「在編輯器中顯示 appsscript.json」→ 打開它，貼上 `fengwei-app/appsscript.json`。
6. 按 **儲存** 💾。
7. 回到試算表並**重新整理**。上方會出現「**風味記帳**」選單，點 **① 初始化**。
   - 第一次會要求授權：選你的帳號 → 進階 → 前往（不安全）→ 允許。這是你自己的程式，所以 Google 會這樣提示。
8. Apps Script 右上 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（App 有 PIN 碼保護）
   - 按「部署」，複製網址（`https://script.google.com/macros/s/……/exec`）。這就是「**同步網址**」。

> 以後更新 `Code.gs` 時：**部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署**。網址不會變，App 不用重設。

## 二、發布 App（約 3 分鐘，只做一次）

1. 到 GitHub 的 `nnnina15/funwayrestaurant` → **Settings → Pages**。
2. **Source** 選 *Deploy from a branch*。
   - Branch 選 `claude/nifty-albattani-nvvc8b`（之後合併到 main，就改選 `main`）
   - 資料夾選 **`/docs`**
   - 按 Save。
3. 等 1–2 分鐘，網址會是：**https://nnnina15.github.io/funwayrestaurant/**

## 三、每台裝置安裝（每台約 1 分鐘）

1. 用瀏覽器打開 **https://nnnina15.github.io/funwayrestaurant/**
   - iPad、iPhone 請用 **Safari**；Android 和電腦用 **Chrome**。
2. 第一次會要求設定：
   - **同步網址**：貼上第一步複製的 `…/exec` 網址
   - **裝置名字**：例如「大埔平板」「Nina 手機」「家裡電腦」
3. 選店別、輸入 PIN 登入。
4. 加到主畫面：
   - iPad／iPhone：分享 → **加入主畫面**
   - Android：選單 → **安裝應用程式**
   - 電腦 Chrome：網址列右邊的 **安裝** 圖示

> **只有第一次設定和第一次登入需要網路。** 之後沒網路也能打開 App 記帳。

## 離線怎麼運作

- 每次按「儲存」或「新增」，資料**先存在這台裝置**，上方狀態列會顯示「**N 筆待上傳**」，清單上也會標「待上傳」。
- 一連上網路就**自動上傳**。沒網路時，每 30 秒會再試一次；打開 App 時也會試。
- 上傳後會把其他裝置的資料一起拿回來，所以手機也看得到平板記的帳。
- **月結總覽、年度總覽**都在裝置上計算，**離線也能看**。年度總覽像舊表的「總計」頁：每月盈餘、各股東分紅、季合計，以及每天平均的營收、人事、電費、水費、各進貨分類，會註明「最後同步時間」和「幾筆待上傳」。
- 點上方狀態列可以**立即同步**。

### 多台裝置同時改

| 情況 | 結果 |
|---|---|
| 兩台都新增進貨、支出、扣除 | 全部保留，不會互相蓋掉 |
| 兩台都改了**同一天**的每日結帳，或**同一個人同一個月**的薪資 | 以**最後修改時間**較新的為準；比較舊的那台會在「⚙ 裝置 → 同步問題紀錄」看到提醒 |
| 網路在上傳途中斷掉 | 會自動重送，**不會重複記帳** |

### ⚠ 要注意

- **還沒上傳的資料只存在那台裝置上。** 那台裝置壞掉，或清除瀏覽器資料，待上傳的資料就會不見。所以有網路時，記得確認狀態列是「✓ 已同步」。
- 「⚙ 裝置 → 登出」會清掉這台裝置的資料。有資料沒上傳時，系統會先警告你。
- 改了 PIN 之後，用舊 PIN 登入的裝置會顯示「需重新登入」。**沒上傳的資料會保留**，重新輸入新 PIN 後就會繼續上傳。
- 用管理 PIN 登入的手機會存有薪資資料。手機要設螢幕鎖，換手機前先按「登出」。
- **PIN 防猜**：同一家店連續錯 5 次會鎖 15 分鐘，並**寄 Gmail 通知試算表擁有者**（信裡有店別、時間、裝置名字）。同一次鎖定只寄一封。

## 常用項目

每日結帳、固定／其他支出、人事的「常用項目」按鈕，在 App「裝置 → 常用項目設定」修改（只有管理 PIN）：改名稱、分類、順序、刪除、新增。存在試算表 `設定_常用項目`，每家店可以有自己的清單（沒設定就用「全部」）。

## 初始化後要先改的設定（在 Google 試算表）

| 分頁 | 要做的事 |
|---|---|
| `設定_店家` | **改掉預設 PIN**（店長 1234、管理 9999） |
| `設定_股東` | 已填：大埔店 豐吉 60／浩勤 20／呀肥 20；中正店 浩勤 65／豐吉 35 |
| `設定_進貨分類` | 已填 19 類，**牛亨從 2026-10 起停用** |
| `設定_員工` | 刪掉範例，填入真實員工。這是預設值，每月在 App 上可以再改 |

設定改了以後，裝置下次同步就會拿到新設定。

## 帳號（每個人一組帳號＋PIN）

在試算表 `設定_帳號` 管理：

| 欄位 | 說明 |
|---|---|
| 帳號 | 登入用的名字，要一字不差（例：Nina、大埔店長） |
| 角色 | `管理`＝全部功能、兩家店隨意切換；`店長`＝每日結帳和進貨 |
| 店別 | `全部`，或列出店名用逗號分開（例：`大埔店,中正店`）。店長只能切換這裡列的店 |
| 啟用 | 填 `否` 就馬上不能用（已登入的裝置也會被登出） |
| 臨時PIN | 新帳號或忘記 PIN 時填。第一次登入一定要改成自己的 PIN，改完自動清掉 |
| PIN(加密) | 系統自動填，**不要改**。連管理者也看不到真正的 PIN |

- PIN 規則：**至少 8 個字元，要有英文字母＋數字＋符號**（例：`Funway#88`）
- 初始化會建一個帳號「管理員」，臨時 PIN 是 `Funway#2026`，請改成你的名字並登入設定自己的 PIN
- 同一個帳號錯 5 次會鎖 15 分鐘並寄信通知
- 自己改 PIN：App「裝置 → 更改 PIN」

## 權限

| 功能 | 店長 PIN | 管理 PIN |
|---|:-:|:-:|
| 每日結帳（照紙本結帳單排版，支出明細自動記進貨／其他支出）、進貨 | ✅ | ✅ |
| 月結總覽、年度總覽、人事、外送對帳、固定／其他支出、分紅扣除 | | ✅ |

店長裝置只會下載**上個月起**的每日結帳和進貨，不會拿到薪資和股東資料。

## 匯入舊資料

1. 把「風味記帳_舊資料匯入」試算表準備好。分頁名稱和欄位要跟這份試算表的資料分頁一樣。
2. 在「風味記帳」試算表點 **風味記帳 → ③ 匯入舊資料**，貼上匯入檔的網址。
3. 已經存在的資料會自動略過（同一天、同一個編號、同一人同一月），**重複匯入不會變兩份，也不會蓋掉 App 已經記的資料**。
4. 第一次使用會要求「讀取其他試算表」的權限，請按允許。

## 計算規則

```
實際營收 = 現場營收 + Panda 實際入帳 + Uber 實際入帳
盈餘     = 實際營收 − 進貨 − 人事成本 − 固定支出 − 其他支出 − 線上支付手續費
可分配   = 盈餘 − 員工分紅 − 年終預留 − 其他扣除
股東分紅 = 可分配 × 各股東比例
```

- 線上支付手續費 = 全支付／LINE Pay 當月收款 − 月底實際入帳（在「外送對帳」填）；還沒填就先用 `設定_店家` 的手續費率估計，總覽會標「估計」。
- 人事成本 = 「薪資」類＋「公司負擔」類。「預支」只影響實發，不算成本。
- 現金差額另外列出，不算進盈餘。要算進去，到 `設定_店家` 改成「是」。

## 報表

大家都看 App 的「總覽」（日／月／年），試算表**平常不產生報表分頁**，同步比較快。
需要給別人看時，按試算表選單 **風味記帳 → ② 需要時產生報表**，會產生 `報表_月結`、`報表_分紅`、`報表_進貨分類`、`警示`（不會自動更新，下次按「① 初始化」會刪掉）。
